> 本文档是个人网站的**视觉宪法**。任何新页面、新组件、新动效都必须先对照本文档；
> 与本文档冲突时，要么改设计，要么先修订本文档（并说明理由），不允许静默偏移。
>

## 0. 一句话定义

晨雾森林 = **磨砂，不抛光**。一切材质是哑光的，一切动效是慢的，一切颜色来自同一家族（雾、苔、墨、枯草）。

## 1. 高级感五律（最高优先级）

1. **同族色，不靠撞色**——层次靠明度和透明度差，不靠色相跳。全站无外来色。
2. **一处动，处处静**——任一时刻屏幕上只有一处明显在动。
3. **慢比快高级**——常驻动效周期 ≥ 15s（雾带 65–95s、萤火虫 16–24s、"现在在做"呼吸点 16s）；交互反馈 0.3–0.6s；没有 1s 以内的"活泼"动画。唯一例外是颗粒：`steps(4)` 的 1.2s 跳帧是胶片颗粒的物理属性，见 §5。
4. **全站只许三种模糊**——背景雾化（雾带 `blur(28px)`，极大极淡，顶掉旧方案里的"光斑"）、玻璃材质（导航 `blur(18px)`／图鉴玻璃条 `blur(14px)`）、入场虚焦（内容照片 `blur(10px)`，0.6s 散开，桌面限定）。其余全实。
5. **数值必须"故意"**——字距、行高、圆角、透明度不许出现默认值气质。

**动效预算（硬约束）：**

| 类型 | 上限 | 备注 |
|---|---|---|
| 常驻循环 | 首屏 ≤ 3（雾带 ×3，或雾带 + 萤火虫），子页面只剩颗粒 | 雾带是"空气"，不算装饰 |
| 入场动效 | 每区块 1 组，区块间不复读 | 组内可错落 |
| 交互反馈 | 每个可点元素 1 个主反馈，悬停变化 ≤ 3 个属性 | 位移/透明度/缩放 |
| `prefers-reduced-motion` | ⚠️ 必须 `animation:none` 并直接落到终态 | 无例外。只把 `animation-duration` 改短**不算降级**——保留 `infinite` 会把它变成 10ms 一次的频闪，比不降级更糟；`scroll-behavior` 也要一起关 |

### 2.3 时段色温（变化幅度必须小于"能说清"的阈值）

| 时段 | 天气词 | 亮色模式变化 |
|---|---|---|
| 05–09 dawn | `fog` | 暖顶最浓 `#EFE7D6`；雾带 `opacity:1`（其余时段 `.75`）——"雾最浓"就靠这一档 |
| 09–17 day | `light` | 基准态，雾散开 |
| 17–20 dusk | `dusk` | 暖顶带枯草金 `#EDE4D2`；⚠️ **枯草金当主角的落地方式** = Hero 斜体词换成 `--straw`，本屏 2 处配额里只用 1 处 |
| 20–05 night | `night` | 仅微青压暗（`--bg-base:#EDF0EA` / `--bg-top:#E4E7DE`）；萤火虫 3 颗（暗色 6 颗） |

⚠️ 暗色不随时段变色（表里暗色列是空的，实现照此保持）。天气词初值必须和 `data-phase` 初值同档——静态 HTML 里写 `data-phase="day"` 就把词填 `light`，别留 `fog`。

### 2.4 对比度纪律

正文 ≥ 7:1；次要文字 ≥ 4.5:1；装饰元素允许淡到快消失——**淡是氛围，正文淡是事故**。

⚠️ 这轮补两条口径，否则 §2.1 和 §2.4 会互相打脸：

1. **尺寸档**：≥24px、或 ≥22px/600 的标题级按 3:1 算（`--moss-deep` 只活在这一档）。
2. **装饰档**：`--ink-3` 归此档——它在白底上的上限就是 2.55:1，"把 `--ink-3` 当正文用"必然违规，别指望调它。首屏的观察日志原本是 `--ink-3`，已提到 `--ink-2`（数字部分再提到 `--ink`，保住 §10.4 的层级）。

**首屏实测**（照片 + 纱罩计入；"含光晕"按 `--halo` 在字形周边约 35% 覆盖估算，§5 铁律 3 的第三层）：

| 首屏元素 | 亮色 | 暗色 | 档位 |
|---|---|---|---|
| Hero 标题 `--ink` | 8.69 ✓ | 10.04 ✓ | 正文档 ≥7 |
| 站名 `--ink-2` | 3.44 → **4.00** | 3.82 → **4.34** | 氛围档 |
| 观察日志文字 `--ink-2` | 3.44 → **4.00** | 4.24 → **4.67** | 标签档 |
| 观察日志数字 `--ink` | 8.93 ✓ | 11.11 ✓ | 正文档 ≥7 |

列表页与正文侧（实色底，无照片）：`--ink` 13.13 / 15.11，`--ink-2` 5.05 / 5.77，`--moss-ink` 7.77 / 9.92，`--ink-3` 2.30 / 4.24（装饰档）。

⚠️ 站名和观察日志的文字停在 4.0 上下，**没到 4.5**，这轮是明知故犯：它们是 15px 签名和 13px 标签，不是要读三遍的正文。再往上推只有两条路，都写在这里备用——

- 提 `--scrim-mid`（亮色 `.14` → `.20`+）：代价是照片中段起雾，而那一段正是晨光最亮的地方；
- 给这两行垫一层玻璃面：代价是首屏多出两块可见的框，§5 的"从雾里走出来"变成"从玻璃后面走出来"。

## 3. 字体与排印

| 角色 | 字体 | 规则 |
|---|---|---|
| 中文标题 | Noto Serif SC 600 | 字距 +2%，松才静 |
| 英文标题/斜体词 | Fraunces（opsz 轴） | 字距 -1.5%，收紧才显贵；**全站只允许 Hero 一个英文斜体词** |
| 正文 | Noto Sans SC 400 | 17px / 行高 1.85 |
| 数字/时钟/日期 | IBM Plex Mono | 等宽数字，杜绝宽度不齐 |
| 标签 | 全小写 + 字距 +8%~14% | 如 `essays · notes`，比大写柔和 |

字号层级：Hero 68（移动 34–44）/ H1 42 / H2 30 / 正文 17 / 说明 14 / 标签 12–13。

⚠️ 这轮的三条口径：

- **H1 42** = `.page-title` 与 `.post-title`，两者 `clamp(32px,6vw,42px)`（原先一处 48、一处 46，都超了档）。**H2 30** = 详情页正文的 `##`（原先 24）。
- **卡片标题不在这套层级里**：B 横条卡 24px、C 纯文字卡 26px、图鉴玻璃条 17px——它们是"石头"不是"标题"，别顺手改成 30。
- **站名用 Fraunces 正体**（`.hero-name` 不套 `<em>`）：Hero 的斜体词只留标题里那一个。原先站名也是斜体，等于同一屏两个斜体词。
- 中文标题字距统一 +2%（`.page-title` 原先是 +4%）。

⚠️ 字体源：本机 Google Fonts 被证书拦截，**必须用 `fonts.loli.net` 镜像**，并保留系统衬线回退。

## 4. 空间系统

- 网格：12 列，内容最大宽 1120px，**正文阅读区收窄 680px**
- 间距：区块间距 120–160px（移动 80），卡片间距 32px，刻意偏大
- 圆角：卡片 20 / 图片 16–24 / 按钮与导航全圆角
- 卡片比例：文章大图卡 16:10，横条卡左 1/3 图，项目卡 4:3 或 1:1
- 留白策略：**每个区块只讲一件事，讲完就让雾进来**；页脚末尾留 200px 空白（书末空白页）

## 5. 背景氛围层规格（照片底 + 矢量氛围）

> **2026-09-27 修订**：背景从"全矢量绘制"改为"用户提供的一对同构图照片"（`public/assets/bg-light.jpg` / `public/assets/bg-dark.jpg`，1536×1024，JPEG q85，均 < 300KB；页面里按 `/assets/bg-*.jpg` 引用）。
> 同构图是这套方案成立的前提——主题切换 = 两张图交叉淡化（0.8s），树不会"跳"。**更换照片时必须亮暗两张同构图一起换。**

从远到近的图层顺序（DOM 顺序即深度顺序）：

| 层 | 内容 | 视差 data-depth | 备注 |
|---|---|---|---|
| 渐变底 | `--bg-top` → `--bg-base` | – | 仅作照片载入前的"雾" |
| 照片底 | 亮/暗两张 `<img>` 叠加，`object-fit: cover`，`inset:-3%` 出血 | 0.02 | 入场 2.2s 淡入（延迟 1.2s）；暗图默认 opacity 0，暗主题淡入覆盖 |
| 纱罩 scrim | 两层：文字区径向纱（`--scrim-text`，⚠️ 22% 60% 处）+ 纵向渐变（顶/中/底三段） | – | 职责：统一色调、文字可读、**底部 97% 处溶为 `--bg-base`**，让首屏照片与下方实色内容无缝相接 |
| 横移雾带 ×3 | 白色雾带（`--mist`），`blur(28px)`，从首屏间隙穿过 | 0.12 | 65–95s 周期，负延迟错相，`opacity:.75`（清晨 1）；照片之上再飘一层"会动的雾" |
| 萤火虫 | 3px 苔绿光点 + 光晕，16–24s 周期 | – | 首屏：暗色 6 / 亮色深夜 3；页脚再守 3（仅暗色）；⚠️ 窄屏（≤720px）一律不上岗；除此之外不出现 |
| 颗粒 | SVG feTurbulence 噪点 | – | 透明度 .035，4 步跳帧，1.2s（§1.3 的唯一例外） |

⚠️ 视差位移 = `data-depth × 100px`（横向）/ `× 60px`（纵向）⇒ 照片 ±2px、雾带 ±12px。§11 里"远 3px/中 8px"是三排林线时代的说法，那两层已经随照片底方案退场。

**纱罩三段值（纵向渐变）：**

| 段 | 亮色 | 暗色 |
|---|---|---|
| 顶 | ⚠️ `rgba(242,244,239,.36)` | ⚠️ `rgba(14,19,13,.60)` |
| 中 | ⚠️ `rgba(242,244,239,.14)` | `rgba(14,19,13,.30)` |
| 底 | `rgba(242,244,239,1)` | `rgba(14,19,13,1)` |

顶段这轮各提了一档：站名那一行（首屏高度约 15%）正压在照片最亮的月雾/晨光上，原来的顶段托不住它。

**照片使用铁律：**
1. 照片只允许出现在**首屏背景**和**内容位**（封面/截图/人像），不允许出现在其他区块背景
2. 首屏背景照片必须带纱罩——原图直出会打破同族色纪律、吃掉文字对比度
3. 文字可读性靠三层保障：纱罩 + 文字光晕（`--halo` text-shadow）+ 首屏信息量层级
4. 场景层高度 = 100vh，照片随滚动动线自然离场，下方内容落在实色 `--bg-base` 上——"从雾里走出来"

**滚动叙事弧线**：首屏雾最浓（照片 + 雾带）→ 越往下内容越实（实色底 + 玻璃卡）→ 页脚再散开。
"从雾里走出来，看清一些东西，再走回雾里。"

## 6. 时间感知系统

- 导航左侧：`06:12 · mistwood · fog`（等宽数字 · 站名 · 天气词）
- 分钟级更新，15s 校准一次；**时钟零动效**，数字静默替换
- 天气词驱动时段色温（见 2.3）
- 访客应感觉"今天早上来和下午来不太一样"，而不是"这网站会变色"

## 7. 观察日志文案系统（人格层）

- 首屏：`03 essays · 04 things · 03 notes`——等宽数字 + 全小写宽字距
- 区块标题旁统一为：`essays — 03 →`、`things — 04 →`、⚠️ `notes — 03 →`（三种同形，别再出现"观察日志 · 03 collected"这种混排）。`about` 没有对应数组，页头就**不放**标签——硬凑一个数字等于撞 §12 的假数字
- ⚠️ 页标题用中文（文章 / 小东西 / 关于 / 碎碎念），标签用英文小写——两层各管一种语言，别在同一层混
- 页脚：`last walk · 2026.09.25 · weather: light rain`——给用户手填的位置
- **铁律：所有数字必须对应真实内容数**——由构建期读取集合长度渲染（`src/content/posts` 的篇数、`src/data/site.js` 的数组长度），页面上写不出假数字；写死的假数字会把"手记"变回"模板"
- 碎碎念模块就叫 `notes`，形态 = 日期 + 一两句话，无标题无卡片

## 8. 动效系统

### 8.1 缓动三档（不许发明第四种）

| 档 | 气质 | 用途 |
|---|---|---|
| 吐纳 | `cubic-bezier(.22,1,.36,1)` 先快后极慢 | 所有入场、悬停位移、颜色/透明度反馈、主题切换 |
| 回弹一点 | ⚠️ `cubic-bezier(.24,1.32,.4,1)`（过头约 4%） | 只给**按下**——`:active` 的 0.98 缩放。卡片上浮走吐纳，两档别混用 |
| 匀速 | linear | 进度线 + 无限循环装饰（雾带、萤火虫、"现在在做"呼吸点） |

⚠️ 浏览器默认的 `ease` / `ease-in-out` 就是第四种缓动，属 §12 禁区——这轮把三处文件里 30 多个 `ease` 清零了。`steps(4)` 只许出现在颗粒上。

### 8.2 Hero 入场时间轴（共 ~2.4s，像一口气慢慢吐出来）

| 时刻 | 事件 |
|---|---|
| 0.0s | 只有渐变底和雾 |
| 0.2s | 名字浮起淡入（12px，0.7s） |
| 0.5s | 标题按行浮起，行间隔 120ms（行内 mask 升起） |
| 1.5s | 斜体词最后落地（单独淡入，像特意停顿后才说出口） |
| 1.4s | 导航玻璃条落下 8px 淡入 |
| 1.2s | ⚠️ 照片底开始淡入，2.2s 走完（最慢的一组，3.4s 落地） |
| 3.4s | ⚠️ 进入常驻状态：雾带漂移，夜里萤火虫上岗（旧版的"三排林线 + 光斑 + 滚动提示"随照片底方案退场） |

⚠️ 窄屏（≤720px）行内 mask 降级为整行升起：`.line` 的 `overflow:hidden` 只在"一行真是一行"时成立，44px 下第二句必然折行，两视觉行会一起升、还甩出一个三字孤行。

### 8.3 交互反馈

- **悬停卡片**：上浮 4px + 投影离地 + 图片放大 1.03（0.5s 吐纳），三属性同时但极轻——"凑近看"。⚠️ 这轮补齐：投影落在 `.cover`（离地的是那块面，透明卡体上打影没有意义），图片 `scale(1.03)`；列表卡从 `<article>` 改成整卡 `<a>`，悬停反馈和点击范围从此是一回事
- **悬停链接**：导航链接下划线从左长出 2px 苔绿；正文链接**下划线加深 + 变粗 1px**（不做滑入，太常见）。⚠️ 已落地（`/essays/<slug>/` 的 `.post-body a`）：静止态 `--moss-ink` + 1px 下划线取 40% 透明度、`text-underline-offset:3px`，悬停时颜色补满、厚度 1px→2px，0.3s 吐纳
- **按下**：下沉 1px 或缩放 0.98，带 3–5% 回弹；**不做涟漪**（太 Material）。⚠️ 已实现：`:active` 缩放 0.98 + 回弹档，落在主题切换钮、文章卡、图鉴卡、页脚链接、上下篇
- **页面切换**：旧内容 0.4s 淡出上浮 8px → 新内容 0.5s 下方淡入，不做花哨转场。⚠️ **未启用**——拆成多页之后没有跨页转场，补它属于新功能而不是修偏
- **主题切换**："日出/日落"——背景 0.8s 先变，文字延迟 0.15s 跟上，光斑最后淡入。⚠️ 实现为"背景/文字同批 0.8s 吐纳 + 两张照片 0.8s 交叉淡化"；"光斑最后淡入"随光斑一起退场

### 8.4 图片加载

先铺一片对应色系的"雾"（主色→浅色渐变），载入后从模糊到清晰 0.6s，像雾散开。杜绝灰框闪烁。

⚠️ 登记实现值：占位雾 = `linear-gradient(150deg, --bg-top, --glass)`；内容照片常驻 `--photo-look`（§10.5 的褪色），入场前多叠一层 `blur(10px)`，`load` 之后 0.6s 吐纳散开。取图失败也照样放行——留一块永久雾比留一个空位更糟。入场虚焦是桌面限定（§11）。
⚠️ 正文图版（`.post-body figure.shot`）同一条链：`.frame` 负责圆角 16 + 占位雾 + 裁切，`img` 走满栏宽不裁比例（`width:100%;height:auto`），图注用 12px 等宽 + .12em 字距的 `--ink-3`。

### 8.5 雾灯 Cursor Lantern（首屏鼠标交互）

> 2026-09-27 新增。首屏此前只有隐性的全景视差，缺一个"鼠标是参与者"的交互；雾灯 = 光标提着一盏看不见的灯，照亮处雾散开。

- **机制**：纱罩 scrim 上以灯位为心开半径 200px 的"洞"（mask 径向渐变：中心 4% 可见 → 72% 处完全恢复），照片在洞里露出原本的清晰度。灯位 lerp 0.06 迟滞——**灯总比手慢半拍**，与吐纳节奏一致
- **浅色 = 日照穿雾**：洞内照片变清晰本身就是奖赏，**不加任何光色**；洞外沿叠一圈极淡白环（雾被挤到光圈外沿）
- **暗色 = 手提雾灯**：同一个洞 + 一层月光色（`--moon`，α ≤ .12）径向微光——暗色照片照穿后仍是暗的，需要光源感才读得出"灯"而不是"洞"
- **预算**：不占常驻动效名额（无鼠标时灯不存在，不渲染）；与全景视差共用一个 rAF 循环；随场景层 100vh 滚出自然离场
- **触发**：仅 `pointer: fine` 且非 reduced-motion；首次 mousemove 才点亮（0.6s 淡入），移动端与键盘访问者面前它不存在
- **禁区补充**：雾灯不许引入第三种光色（枯草金不行，会破每屏 2 处上限）

### 8.6 惊起萤火虫 Startled Fireflies（彩蛋交互）

> 2026-09-27 新增。与雾灯共存的"生命感"彩蛋：萤火虫不是贴图，是会被手惊动的小东西。

- **触发**：光标速度 > 1.2px/ms（快速划过）且距萤火虫 < 130px；**慢速靠近不触发**——鼓励轻轻地动
- **时序**（共 ~4s）：原地冻结 → 0.25s 熄灭 → 弧线逃逸（1.4s 吐纳，背离光标 60–110px、略向上 30px）→ 逃逸途中重新亮起（0.8s）→ 隐去并回到原有明灭节律。⚠️ "弧"是两段拼出来的：0.5s 横着弹开（走 72% 位移、30% 上扬）+ 0.9s 继续飘出去并上抬——单段直线只是"逃"，两段才有"弧"
- **上限**：同屏至多同时惊起 3 颗；惊起中的萤火虫有 4s 冷却，不会被打断第二次
- **预算**：事件驱动，非常驻；与雾灯/视差共用一个 rAF 循环
- **缺席即合理**：只在萤火虫在岗时存在（暗色 / 亮色深夜）；亮色白天没有它，不补假货

### 8.7 内容区滚动入场

- IntersectionObserver（threshold .15）触发：升起 16px + 淡入，0.8s 吐纳，**只演一次**（unobserve）
- 同帧进入视口的元素用 transition-delay 错落 80ms——像目光扫过去依次看清，不是整板拍上来
- reduced-motion：直接落到终态，无位移

## 12. 禁区清单

- ❌ 纯黑背景 / 纯白卡片（永远带一点青绿倾向）
- ❌ ️ 纯黑阴影——暗色 `--shadow` 也用夜林色 `rgba(14,19,13,…)`，不用 `rgba(0,0,0,…)`
- ❌ 撞色、外来色相（紫、亮蓝、纯橙等）
- ❌ 第四种模糊、第四种缓动（⚠️ 浏览器默认 `ease` / `ease-in-out` 就是第四种）
- ❌ 涟漪动效、弹簧弹跳、1s 内的活泼动画
- ❌ ⚠️ `prefers-reduced-motion` 下还留着 `infinite`——哪怕时长被压到 10ms，那比不降级更闪
- ❌ 照片无纱罩直出 / 亮暗不同构图的照片对
- ❌ 照片出现在首屏背景与内容位之外的任何地方
- ❌ ⚠️ 占位提示压在真图上（封面/截图那类 `::after` 必须 `:not(:has(img))` 才成立）
- ❌ ⚠️ 死锚点：跨页导航只许指向真实存在的页面或锚点（首页拆过区块，`index.html#things` 这类地址已经不成立）
- ❌ 大写标签（全小写宽字距）
- ❌ 假数字、Lorem ipsum 式占位文案
- ❌ 每屏超过 2 处枯草金（傍晚时段除外）
- ❌ ⚠️ 把 `--ink-3`（装饰档）或 `--moss-deep`（大字档）用在正文级小字上——见 §2.4

  - **链接**：站内相对路径、`#锚`、`http(s)`、`mailto:` 之外的一律拒绝（`javascript:`/`data:` 会变成 `href="#"`）；外链自动补 `target="_blank" rel="noopener noreferrer"`。md 里写的原始 HTML 会被转义成文字，不是漏洞也不是特性。
  - **路径一律钉到站点根**：详情页在 `/essays/<slug>/` 这一层，相对路径按旧站习惯写会解析到 `/essays/assets/…`。渲染器会把 `assets/x.jpg`、`./assets/x.jpg`、`things.html` 统一改写为 `/assets/x.jpg`、`/things/`（`tools/check-markdown.mjs` 钉着这条），但**图片路径仍必须自己带开头的斜杠**——Astro 在构建期解析 md 里的相对图片路径，文件不存在就 `[ImageNotFound]` 失败，轮不到渲染器救。素材放 `public/assets/posts/<slug>/`。
  - ~~file:// 双击取不到 md~~ → 迁移后正文就在 HTML 里，`dist/` 用任何静态服务器都能开，**不再有运行时 fetch 依赖**（旧版那条"必须起 http.server"的限制随 fetch 一起消失）
- **文章列表页**：B 横条卡为主力（有 excerpt 即 B，奇偶左右错落），无 excerpt 渲染为 C 纯文字卡（右让 60px）；⚠️ 整卡就是一个 `<a>`，不是"标题可点、别处只给悬停反馈"；A 大图卡随首页区块拆除已退役
- **文章详情页**：正文 Noto Serif SC 400 / 18px / 行高 1.9 / 栏宽 680；H2 30px（§3 的档）带 32px 苔绿短线起头；正文内斜体词用 `--moss-ink` 不是 `--moss-deep`（18px 属正文级）；进度线 2px 苔绿匀速（linear 的合法用途即进度线，见 §8.1），⚠️ 载入时就要算一次，否则带滚动位置刷新进来时进度线从 0 开始（旧版还要等 fetch 落地，现在正文就在 HTML 里）；目录 JS 从 H2 生成（H2 的 `id` 由脚本补，构建期不写），>1240px 吸附右侧、滚动高亮，移动端隐藏（⚠️ 目录靠 `animation` 显形，减弱偏好下要直接给终态，否则永远不透明）；上下篇 = 按 `date` 倒序排完之后的数组邻居（⚠️ 不再手维护顺序，日期即顺序），大号文字链接（同页脚语言）；`<title>` 与 `meta description` 由构建期按当前文章写入，模板里不许写死某一篇
- **notes**：日期 + 一两句话，无标题无卡片，条目间距 56px，栏宽 680；条数与首页观察日志天然一致（同一数组）
- **页脚**：各页同版式，萤火虫只守首页页脚

## 16. 日常写作与构建

> 这一节不管视觉，只管"新增一篇文章要敲哪几条命令"。规范其余章节约束的是**写出来的东西长什么样**，与此处互不覆盖。

- **写一篇新的**：`npm run new-post <slug> "标题" [--date 2026.09.27] [--excerpt "一句话摘要"]`
  - slug 只允许小写字母 / 数字 / 连字符（它直接进 URL），日期要 `YYYY.MM.DD`，同名文件**不覆盖**
  - 有 `excerpt` → 列表页出 B 横条卡；留空 → C 纯文字卡（§15）
  - 骨架里那行示例图是**哑的**（括号里带空格），删掉空格才变成真图；这样图还没到位时 build 不会红
- **发布前**：`npm run check` —— 一条命令查两类事：每篇 front matter 合不合 schema、正文里有没有会炸 build 的相对图片路径；以及排版渲染器的回归（图版/链接/白名单/属性注入，`tools/check-markdown.mjs`）
- **本地看**：`npm run dev`（带热更新）；`npm run build` 出 `dist/`，`npm run preview` 起本地静态服务看成品
- ⚠️ **上线前必改的两处**：`astro.config.mjs` 的 `SITE` 现在是占位域名 `https://mistwood.example.com`，它同时决定 `sitemap-0.xml` 与 `rss.xml` 里的绝对地址；页脚 github 仍是 `#`（§13）
- ⚠️ **托管到 Vercel 一类平台必须自带域名**：本网络下 `vercel.com` 可达但 `*.vercel.app` 被 DNS 污染且连接被重置，用默认二级域名等于自己做不到可验证；绑域名的代价是要自己持有一枚域名，这是既定约束不是选择题
- **RSS**：`rss.xml.js` 按 `date` 倒序输出，条目正文用的是 front matter 的 `excerpt`（**不是全文**，`excerpt` 留空时退回标题），`<link>` 用 `SITE` 拼绝对地址——所以 `SITE` 没改就发布，订阅者点进来的链接会落到占位域名

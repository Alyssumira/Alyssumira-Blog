# 视觉优化头脑风暴提案 · 第三轮（2026-10-01）

> 诊断：现在的晨雾森林是"一本排印很好的纯文字册子"——全站的视觉几乎 100% 由文字排版承担，图形语言约等于零（唯二的图形：年度弧、首屏照片）。前两轮解决了"淡"（色彩/光/字重），这一轮解决"字多形少"。
>
> 纪律口子继续开着，但本轮自己先立一条总闸，防止"加图形"滑成"贴装饰"：
>
> ## 总闸：三种图形母题，全站只许从这三族里长
>
> 图形一多就会各自为政。晨雾森林的图形只允许三个母题，全部从既有意象里抽：
>
> 1. **雾线（横的）**——从雾带抽出来的：一条或多条平行的、缓变的水平曲线/直线族。气质=空气、时间、远处。
> 2. **苔点（点的）**——从颗粒与萤火虫抽出来的：圆点、点阵、点的聚散。气质=生命、计数、记录。
> 3. **年轮弧（圆的）**——从年度弧抽出来的：圆弧、扇形、不完整圆。气质=岁月、周期、进度。
>
> 全站任何新图形，必须能指认自己是这三族里的哪一族。**禁止的第四族：具象插画**（树、鹿、房子、山形剪影）——那是"森林主题模板"的语言，不是"晨雾森林"的语言；一条 SVG 松树贴上去，前两轮攒的所有高级感当场清零。
>
> 第二道闸（沿用 §7 铁律）：**凡图形表达数据，数据必须真实可复算**；凡纯装饰，必须承认自己纯装饰，不许伪装成信息。

---

## 一、数据图形：让"这本手记"第一次被看见

这是本轮收益最大的一组——博客最天然的图形素材就是**写作行为本身**，而且全部是真数据（构建期从稿件与 git 历史算出来，零运行时、零第三方）。

### 1.1 · 写作年轮图（母题：年轮弧）
- 关于页/列表页侧栏：一枚环形图，一圈 365 格，每一格是过去一年的一天，写了稿的日子填 `--moss`（字数多寡映射深浅，沿 `--moss-ink`→`--moss` 明度轴走，零新色）。
- 与既有年度弧的关系：年度弧是"今年走到哪"，这枚是"今年写在哪"——一个记时间，一个记行为，互补不重复。
- 数据出处：`src/content/posts/*.md` 的日期与字数，构建期生成 SVG，产物逐字节可复算。
- 与 §12 的对账：§12 否过"给年度弧补读数"（"第 N 天""xx%"那族），那条禁的是**给静态形状挂要逐日核对的数字读数**；本图本身是数据本体、不挂读数，形状即数据。落笔前把两条摆在一起给作者判一次。
- 变体（更便宜的版）：不是环，是一横条 365 格（GitHub 贡献图的森林版，一行排开、按月轻轻分段）。环更"年轮"，条更克制，建议先做条、环留升级位。

### 1.2 · 字数密度尺（母题：雾线）
- 列表页每篇文章行的右端（或悬停时）：一条极细的横向雾线段，长度=该篇字数按全站最大值归一。
- 注意 §12 里否过"1 min = 20px"那族——理由是**比例尺没有出处**。本提案的解法是按那条否决自己开的药方：尺子由这批稿子自己定标（`h = len/maxLen`，峰值归一），与 §15 密度尺同一套口径，没有一毫米来自拍脑袋常数。
- 收益：列表页从"纯文字目录"变成"一眼看出哪篇长哪篇短"的可视化目录。

### 1.3 · 引用与出处的"书脊"（母题：雾线）
- 文章里引文块（blockquote）现在是左竖线。升级：竖线改为一族 3 条不等长的雾线（1px，长度 32/20/12px 错落），读起来是"这段话来自远处的另一本书"。
- 纯装饰、承认纯装饰；零新色（`--moss` 族）；与"32px 苔绿短线=章记号"的冲突要核——章记号是单条 32px，引文是三错落条，形状不同族。落笔前过"同一符号两种意思"那道闸。

### 1.4 · 站点档案的图形化（关于页）
- 关于页"站点档案"现在是一串 `dt/dd` 文字。把其中能图形化的三项换掉：
  - "写了 N 篇 / 总字数" → 苔点阵：每篇一枚苔点，点径按字数归一，排成一条散点河；
  - "建站天数" → 一段年轮弧（弧长=天数/365）；
  - "载入次数"（localStorage 那枚真数）→ 不图形化，维持文字（它是读者本机的数，不是站的内容）。
- 全是已存在的真数字，只是把"读数字"换成"看形状"。

## 二、装饰图形：给每一页一个"页头形状"

**诊断：子页面的"平"，一半是图形缺位——每个页头只有标题文字，没有一枚图形接住视线。**

### 2.1 · 页头雾线族（母题：雾线）——本轮最便宜的"图形化"
- 每个子页标题下方，一族 3–5 条水平雾线（SVG 或 CSS 渐变），从上到下透明度渐隐、间距渐宽，读起来是"标题沉进雾里"。
- 各页参数不同：`/essays` 密而淡（目录=平静）、`/about` 疏而长（关于=舒展）、`/things` 短而断（物件=散落）、404 浓而乱（lost 档本来就有"雾最浓"的授权）。
- 零新色（`--ink-3`/`--moss` 族透明度），静态无动画，reduced-motion 天然免疫，打印档退成单线。
- 与 §1.4 三种模糊无涉（是线条不是模糊）；不占任何动效名额。

### 2.2 · 分隔符图形（母题：三族合流）
- 文章内 `---` 分隔、列表页年份分节：现在是文字或发丝线。换成一枚居中的小图形：**一条雾线 + 中央一枚苔点 + 点外一圈极淡的不完整弧**——三母题各出一笔，组合成全站通用的"换气记号"。
- 全站只此一枚分隔图形，任何地方要分隔都用它（可缩两档大小）——这就把"图形语言"立成了系统，而不是散件。

### 2.3 · 文章页头的"题花"区
- 详情页标题区现在只有标题+日期。在标题上方加一块窄幅题花：雾线族横贯版心，中央按文章主分类（若将来有）换一族参数——目前是"雾线 3 条"固定版。
- 注意与第一轮 D1"首屏引子"不冲突：那个在首页，这个在文章页。

## 三、内容图形：照片与物件的"形"

### 3.1 · 文章封面位（真照片，不是插画）
- 列表页目录行左侧留一枚 4:3 小封面槽：稿件 frontmatter 里指定照片则显示，没指定就显示雾线族占位（**承认是占位**，不假装有图——§12 那条"空盒是真的"的同一族）。
- 照片纪律照旧：亮暗成对、纱罩三笔账。这一步把列表页从"纯文字"升级成"文字+缩略图"的现代博客标准形态。
- 成本：要处理"没图的行怎么办"的排版对齐（建议：无图行封面槽整槽不渲染，文字左缘对齐，不留空位）。

### 3.2 · /things 物件页的"图鉴格"
- 现状是横条列表。换成网格卡片：每张卡 4:3 照片位 + 名字 + 一行注。空槽照样画 4:3 雾线占位（沿用现状"空盒是真的"的授权）。
- 这是全站最适合"网格化"的一页——物件本来就是"摆出来"的。

### 3.3 · 照片图注的"底片框"
- 内容照片的图注从纯文字升级为：图注文字前加一枚极小的"底片齿孔"记号（2 枚 2px 苔点竖排，母题②）——承认"这是一帧照片"这件事。
- 极小、极便宜，但它是"图形语言渗透到细节"的那类动作。

## 四、身份图形：站外的三张脸

**诊断：站内再美，分享出去/收藏夹里/打印纸上全是"无图形状态"。**

### 4.1 · OG 图模板
- 现状：`og-check` 在守 OG 元数据，但图本身需要一枚模板。立一枚构建期生成的 OG 图版式：雾白底 + 标题大字 + 底部一条深苔实面（§二轮 1.1）+ 苔点一枚。
- 每篇文章构建时烘一张（Satori/纯 SVG→PNG 均可，进构建链，可复算）。
- 这是"现代化"最立竿见影的一项——微信/Twitter 分享卡片是现在读者见到这个站的第一面。

### 4.2 · favicon 与触摸图标
- 母题②：雾白圆角方底 + 一枚苔点 + 苔点外一圈不完整弧。16px 下退成纯苔点（弧在小尺寸糊掉，这是图形系统的"降级谱"的一部分，要写进规范）。
- 与第一轮 A1"晨标"共用同一枚图形语言——A1 若立，favicon 就是它的最小号。

### 4.3 · 404 的"浓雾图"
- §12 给 404 留过口子："树影铺满子页"被否，但**404 专属**被点名是正确形态（"那一页的 lost 档本来就有雾最浓的授权，场景在那儿是内容而不是抢戏"）。
- 落法：雾线族在这里第一次允许"乱"——多组雾线交叉、透明度打到上限，中央一枚苔点都不给（迷路了，没有生命迹象）。这是全站唯一"图形当主角"的页面。

## 五、滚动中的图形（谨慎的一枚）

### 5.1 · 文章进度弧（母题：年轮弧）
- 窄屏阅读时，右上角一枚直径 28px 的不完整圆弧，随滚动走完一圈——进度条的森林版。
- 与 §12 对账：进度条本身没被否过（被否的是"年度总结"那族平台语言与"给年度弧补读数"）；这枚弧不挂任何数字读数，纯形状。
- 闸：只窄屏出现（桌面有目录高亮承担同一职责，C4 已述）；滚动驱动、无 animation、reduced-motion 下整枚不渲染。
- ⏸ 这条是全轮唯一带交互的，排在最后做。

## 七、本轮自查

- 母题纪律：以上每一枚图形都能指认自己属于雾线/苔点/年轮弧哪一族；零具象插画；
- 色彩：零新色（全部 `--moss`/`--ink-3`/`--moss-solid` 族 + 透明度）；
- 动效：仅 5.1 一枚滚动驱动，其余全静态；
- 数据：所有"信息图形"的数据都是构建期从真实稿件算出来的真数，零编造、零运行时请求；
- 被松动的旧账只有两处要回规范过闸：① 1.1 与"年度弧补读数"否决的边界确认；② 1.2 的比例尺按"峰值归一"口径备案（这其实是被否条目自己开的药方，算执行不算破例）；
- 与一二轮的关系：本轮的深苔页脚/深苔按钮/选中色（二轮）与页头雾线/分隔符（本轮）拼起来，就是"淡+字多"两个诊断的完整解——**色彩负责浓，图形负责形，排印负责气**。
